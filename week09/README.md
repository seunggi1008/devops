# 9주차 쿠버네티스

## 1. Kubernetes 노드 확인

minikube를 사용해서 쿠버네티스 클러스터를 실행했다.

## 2. Pod 삭제 후 자동 복구 확인

Pod 하나를 삭제했는데 자동으로 다시 생성됐다.

## 3. 내 방명록 실행

내가 만든 방명록 이미지를 쿠버네티스에서 실행했다.
처음에는 ContainerCreating 상태였는데
조금 뒤 Running 상태로 바뀌었다.

포트 포워딩을 해서 localhost:8080으로 접속했다.


## 4. 선언형
선언형은 원하는 상태만 정해 놓으면 시스템이 알아서 맞춰주는 방식이다.
예를 들어 에어컨 온도를 24도로 설정하면 알아서 그 온도를 유지하는 것과 비슷하다

## 5. 막힌것 , 해결방법
처음에 minikube를 실행했을 때 Docker 연결 오류가 발생했다.
Docker Desktop 설정을 확인하고 ChatGPT의 도움을 받아 WSL을 다시 실행하니 해결됐다.

그리고 mynginx를 Deployment로 삭제하려고 했는데 오류가 났다.
ChatGPT에 오류를 물어보고 확인해 보니 Deployment가 아니라 Pod여서 명령어를 바꿔서 삭제했다.
