# DevOps 3주차

## 1. 셸 스크립팅 실습

셸 스크립트를 이용하여 여러 명령어를 한 번에 실행하는 방법을 배웠다.

반복해서 명령어를 입력하지 않고 스크립트 파일로 만들어 실행할 수 있다.

## 2. 셸 스크립트 실행 방법

`#!/bin/bash`: Bash 셸을 사용하여 스크립트를 실행한다.

`chmod u+x start.sh`: 스크립트 파일에 실행 권한을 준다.

`./start.sh`: 현재 폴더에 있는 스크립트를 실행한다.

## 3. Qwen과 Ollama 실습

Ollama를 이용하여 Qwen 모델을 실행하는 방법을 배웠다.

`chat.py`는 Python으로 작성된 웹 프로그램이며, Ollama와 연결하여 질문과 답변을 처리한다.

`start.sh`를 이용하면 실행 명령어를 매번 직접 입력하지 않아도 된다.
