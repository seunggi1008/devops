# DevOps 3주차

## 셸 스크립트 실습

셸 스크립트를 이용하면 여러 명령어를 한 번에 실행할 수 있다.

chmod u+x start.sh: 실행 권한 부여

./start.sh: 셸 스크립트 실행

## Qwen 실습

Ollama와 Qwen을 이용한 웹 프로그램 실행 방법을 배웠다.

chat.py는 Python 프로그램이고 start.sh는 실행 스크립트이다.

## 환경 변수

export 명령어로 환경 변수를 설정하는 방법을 배웠다.

start_with_export.sh를 이용하여 환경 변수를 설정하는 실습을 했다.
