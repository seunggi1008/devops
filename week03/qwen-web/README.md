# DevOps 3주차

## 셸 스크립트 실습

셸 스크립트를 이용하면 여러 명령어를 한 번에 실행할 수 있다.

`chmod u+x start.sh`: 파일에 실행 권한을 준다.

`./start.sh`: 셸 스크립트를 실행한다.

## Qwen 실습

Ollama와 Qwen을 이용한 웹 프로그램 실행 방법을 배웠다.

`chat.py`는 Python으로 만든 프로그램이고 `start.sh`는 실행할 때 사용하는 스크립트이다.

## 환경 변수

`export` 명령어로 환경 변수를 설정하는 방법을 배웠다.

`start_with_export.sh`를 이용하면 환경 변수를 설정해서 프로그램을 실행할 수 있다.

## 실습하면서 알게 된 점

셸 스크립트를 사용하면 명령어를 매번 입력하지 않아도 돼서 편리하다.

실행 권한이 없는 경우에는 `chmod` 명령어로 권한을 설정해야 한다.
