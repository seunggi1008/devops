# 3주차 - 셸 스크립팅

## 1. 학습 목표
- 셸 스크립트를 활용하여 반복 작업을 자동화하는 방법을 학습한다.
- 실행 권한과 환경 변수의 역할을 이해한다.
- Ollama와 Qwen을 이용하여 로컬 AI 웹 서비스를 실행하는 방법을 학습한다.

## 2. 실습 내용
이번 실습에서는 Python 웹 프로그램과 Ollama를 연결하여 로컬 AI 웹 서비스를 구성하는 방법을 배웠다.

GitHub에 업로드한 파일:
- `chat.py`: 질문을 입력받고 Ollama API를 통해 답변을 출력하는 웹 프로그램
- `start.sh`: 프로그램 실행을 위한 셸 스크립트
- `run_py.sh`: Python 실행 관련 셸 스크립트
- `start_with_export.sh`: 환경 변수 설정 관련 셸 스크립트

## 3. 주요 개념
- `#!/bin/bash`: Bash로 스크립트를 실행하도록 지정한다.
- `chmod u+x`: 파일에 사용자 실행 권한을 부여한다.
- `./start.sh`: 현재 디렉터리의 스크립트를 실행한다.
- `export`: 환경 변수를 설정하여 실행할 프로그램에 전달한다.
